# Welcome to 0xTools

0xTools is your all-in-one Solidity developer toolkit, right inside VS Code.

- **Signatures** — extract function selectors, event topics, and error selectors.
- **Real-time gas** — inline gas annotations that update as you type.
- **Security analysis** — reentrancy, access control, MEV, DeFi risks, and more.
- **On-chain inspection** — read live contract state, balances, and transactions.
- **Deploy & Run** — compile, deploy, interact with, and verify contracts.

> **Tip:** Run **0xTools: Show All Commands** from the Command Palette to browse every feature by category.
