# Scan a Project for Signatures

Scanning extracts every function selector, event topic, and error selector across your contracts.

Open a Solidity project, then run the scan. Results appear in the **Contract Signatures** explorer view, where you can copy a selector or signature with a click.

> **Command:** Run **0xTools: Scan Project for Signatures** from the Command Palette. From the explorer, use **Copy Function Selector** or **Generate ABI from Signatures**.
