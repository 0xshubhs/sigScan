# Security Analysis

0xTools surfaces security issues directly in your editor and collects them in the **Findings** view.

It detects reentrancy, access-control gaps, MEV exposure, DeFi risks (oracle, precision, approval), unchecked calls, and dangerous patterns like `tx.origin`. Many findings come with one-click quick-fixes via the editor lightbulb.

> **Command:** Try **Detect Reentrancy Vulnerabilities**, **Check Access Control**, or **Analyze MEV Risks** from the Command Palette — or run **Run Slither Analysis** for a deeper audit.
