# Deploy & Run

The **Deploy & Run** sidebar lets you take a contract from source to a live address without leaving VS Code.

Compile your contracts, deploy to a local or remote network, call functions and read return values, send payable value, and verify your source on a block explorer.

> **Keybinding:** Press `Cmd+K D` (macOS) or `Ctrl+K D` (Windows/Linux) to open the panel, or run **Show Deploy & Run Panel**.
